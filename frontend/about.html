Project Overview

HealVision is an intelligent healthcare assistant designed to predict diseases based on symptoms and provide personalized recommendations such as medicines, precautions, diet, and lifestyle suggestions. It combines AI/ML models with a structured knowledge base for reliable, real-time results.

Technology Stack

🧠 AI/ML

Random Forest, XGBoost

⚙️ Backend

Flask + MongoDB Atlas

🎨 Frontend

HTML, CSS, JS, Bootstrap

🤖 Chatbot

Hugging Face + Groq API

Key Features

🩺 Disease Prediction

Predicts diseases from symptoms with medicines, precautions, diet, and workouts.

🤖 AI Chatbot

Interactive chatbots for symptom-based guidance, general Q&A, and lifestyle advice.

🍎 Diet & Lifestyle

Personalized diet and workout recommendations for recovery and prevention.

🆘 Emergency Guidance

Detects serious symptoms and suggests immediate medical attention.
